# Smart Expense Tracker 💰

A Python-based expense tracking and spending analysis project using Pandas and Matplotlib.

## 📌 Project Overview

Smart Expense Tracker helps users record their expenses and analyze spending patterns based on different categories.

## 🎯 Objectives

- Record expense details
- Calculate total expenses
- Analyze category-wise spending
- Identify the highest spending category
- Visualize expenses using charts

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV
- Google Colab

## ✨ Features

- Expense data recording
- CSV file handling
- Total expense calculation
- Category-wise expense analysis
- Highest spending category detection
- Bar chart visualization
- Pie chart visualization

## 📊 Project Analysis

The project analyzes expenses such as:

- Food
- Travel
- Shopping
- Education

Pandas is used for data processing and analysis, while Matplotlib is used to create visualizations.
